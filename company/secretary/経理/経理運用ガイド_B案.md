## 1. これだけ：俊さんの毎月の作業（月初・5営業日以内）

前月分を書き出して、Googleドライブの下記フォルダに置く（または、この会話に添付）だけ。

```
経理/
├─ CSV/
│   └─ 2026-07/           ← 月フォルダを作り、その中へ
│        ├─ square_2026-07.csv     （Square 売上）
│        ├─ bankA_2026-07.csv      （銀行① 入出金明細）
│        └─ bankB_2026-07.csv      （銀行② 入出金明細）
├─ 領収書/
│   └─ 2026-07/           ← 経費レシートは写真を撮って置くだけ
└─ 月次帳簿/               ← ★ここはゆきの成果物置き場（仕訳・試算表・レポート）
```

### CSVの書き出し方（目安）
- **Square**：Square データ／ダッシュボード → 「取引」または「売上レポート」→ 期間を前月 → **CSVで書き出し**。売上・**決済手数料**・入金額が含まれるものを。
- **銀行①②**：各ネットバンキングの「入出金明細」→ 前月 → **CSVダウンロード**。
- ※ CSVが開きにくい銀行は、**この会話にファイルを添付**いただければゆきが読み取ります。

## 2. ゆきの毎月の作業（CSVが揃い次第）

1. CSVを読み取り、**仕訳ドラフト**（勘定科目つき）を作成
2. **月次試算表**・**入出金サマリー**（銀行別・科目別）を作成
3. **受注フォームの売上と照合**（入金漏れ・二重・ズレを検知）
4. **Square手数料**を「支払手数料」として自動計上
5. **月次経理レポート**として、この会話＋スマホ通知＋`company/secretary/経理/月次帳簿/YYYY-MM/` に保存
6. 未処理・要確認（不明な入出金、レシート不足等）を**リストアップ**してお知らせ
