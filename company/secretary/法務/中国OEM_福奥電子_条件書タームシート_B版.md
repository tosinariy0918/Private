## 2. 取引の枠組み（2026-09-10 変更：販売代理・委託型）
| 項目 | 内容 |
|---|---|
| 契約類型 | **OEM製造 兼 独占的販売代理（委託）契約**（乙は買主ではなく**販売代理人**。甲が乙へ手数料を支払う） |
| 主たる対象 | **OEM商品**（乙の要望に基づき甲が仕様確定・製造する規格外サイズ等）＋本商品（CBチップ・CBスティック等） |
| 製造・所有 | **甲がOEM製造**し、商品を所有（委託販売の場合、在庫は原則甲に留保） |
| 仕様の最終決定権 | **甲**に帰属（第3条2項） |
| 販売地域 | **中国国内**（香港・マカオ・台湾を除く） |
| 乙の役割 | 中国における**独占的販売代理人**（甲の商品を販売し、甲から販売手数料＝マージンを受領。域外販売・輸出・越境EC禁止） |
| 製造への関与 | 乙は製造・加工に一切関与しない |

## 4. 価格・手数料・決済（2026-09-10 確定／代理・委託型）
| 項目 | 内容 |
|---|---|
| 中国での指定販売価格 | **270円／枚（税別）確定** |
| 乙への販売手数料（マージン） | **50%＝135円／枚（甲が乙へ支払う）** |

| 代金回収 | **要確定**：末端代金の回収主体（乙が回収し甲へ送金／甲が請求）・送金時期・手数料の相殺・通貨（円/元） |
| 支払方法・時期 | **要確定**（前払／L/C／T/T等） |
| ※要弁護士確認 | 乙＝**販売代理（委託）**として第1・4・7・8条を修正（卸値概念→手数料へ）／RPM（指定販売価格遵守）の競争法適法性／会計は総額270円計上＋手数料148.5円（税理士確認） |
