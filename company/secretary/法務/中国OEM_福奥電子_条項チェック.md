## 2. よくできている点（強み）
- **知財保護が極めて手厚い**（第9〜13条）：本知財は甲単独帰属／改良成果も甲帰属／リバースエンジニアリング・冒認出願・類似品製造を全面禁止／**競業避止5年**／**秘密保持は営業秘密につき無期限**。
- **独占権に最低購入コミット**を紐付け（第4条：年**最低12ロット＝60,000枚**）。未達で非独占化又は解除でき、乙は損失請求不可。
- **違約金3,000万円＋侵害品1枚あたり正規価格の3倍＋違約罰**（実損の上乗せ請求可）（第19条）。差止め請求も可。
- **紛争解決＝仲裁（JCAA・東京）**：中国では外国判決の執行が困難な一方、仲裁判断はニューヨーク条約で執行しやすく、合理的。
- 日本語正本優先（第23条）・完全合意（第24条）・**譲渡禁止**（第20条）・帳簿調査権（第11条4項）。

## 4. リスク・弁護士／弁理士に要確認（重要）
| # | 論点 | 内容 |
|---|---|---|
| ① | **再販売価格の拘束（RPM）** | 第8条2項「指定販売価格の遵守」は、日中の**競争法（独禁法）でリスク**。「推奨小売価格」化 or 独占枠内運用の適法性を要確認。 |
| ② | **中国商標の早期出願** | 相手が中国企業のため**冒認出願対策が急務**。マドプロ又はCNIPA直接出願で「電子CB農法」「CBチップ」等を早急に。 |
| ③ | **PCT国内移行の期限** | 優先日から**30か月以内**に中国国内移行が必要（期限管理）。PCT自体は権利を付与しない。 |
| ④ | **実用新案の行使準備** | 日本の実用新案は無審査登録。警告・差止には**技術評価書**の取得が前提。 |
| ⑤ | **既存特許7444353の中国保護可否** | 優先権期間経過等で中国保護が及ぶか弁理士確認。新PCTとの関係整理。 |
| ⑥ | **違約金3,000万円の有効性** | 中国民法典では実損を著しく超える違約金は**減額されうる**。金額の妥当性を確認。 |
| ⑦ | **検品期間30日**（第7条） | 甲有利だが、乙が「短い」と渋る可能性＝**交渉ポイント**。 |
| ⑧ | **製造物責任（第15条）** | 第三者PL損害の最終負担・**PL保険の付保**を検討。 |
| ⑨ | **秘密保持の除外事由なし**（第12条） | 公知情報・独自開発・法令開示命令等の一般的除外がなく、乙が追加を求める可能性。 |
| ⑩ | **仲裁地の選択** | JCAA東京が既定だが、中立性でSIAC（シンガポール）/HKIAC（香港）も検討余地。 |
| ⑪ | **相手方の与信・実在性（DD）** | 表明保証はあるが、**登記簿・与信・署名権限**のデューデリを推奨。 |
