# 自治体データマップ ─ e-Stat 実データ取得サンプル

概算・ダミーだった従来版に対し、**e-Stat（政府統計の総合窓口）API から河内長野市の実データ（人口・面積）を取得し、出典・統計年次つきで表示する**最小プロトタイプです。サーバー不要、単一の `index.html` だけで動きます。

## 使い方（3ステップ）

前提：e-Stat のアプリケーションID（無料）を取得済みであること。

1. **ファイルを開く** … `index.html` をダブルクリックし、ブラウザで開きます。
2. **IDを貼る** … 画面上部「e-Stat アプリケーションID」欄に、取得済みのIDを貼り付けて「保存」を押します。
3. **取得する** … 「河内長野市のデータを取得」ボタンを押すと、e-Stat から人口（可能なら面積も）を取得し、出典「政府統計の総合窓口（e-Stat）」と統計年次つきで表示します。

IDはお使いのブラウザ内（`localStorage`）にのみ保存され、コードやリポジトリには一切残りません。共有PCでは使用後に「クリア」を押してください。

## 技術メモ

### エンドポイント
- `https://api.e-stat.go.jp/rest/3.0/app/jsonp/getStatsData`（getStatsData / JSONP形式）

### CORS / JSONP の結論（重要）
- e-Stat API はブラウザからの通常の `fetch`（CORS）では原則ブロックされます。
- ただしAPI仕様に **JSONP形式（`callback` パラメータ）** が用意されており、`<script>` タグ経由で読み込むためCORSの制約を受けません。
- したがって本サンプルは **JSONPを採用し、サーバー・プロキシ無しの純クライアントサイドでデータ取得が可能** です。Vercelサーバレス関数等のプロキシは今回不要でした。
- （補足）本番版でAPIキーをサーバ側に隠したい・レート制御したい場合は、将来的にサーバ経由に切り替える設計も選択肢になります（今回はまず「取れる形」を優先）。

### 使用データ（社会・人口統計体系「市区町村データ」基礎データ表）
| 項目 | statsDataId | 項目コード | 地域コード |
|---|---|---|---|
| 人口（総人口） | `0000020201`（人口・世帯） | `A1101` | `27216`（河内長野市） |
| 面積（総面積） | `0000020202`（自然環境） | `B1101` | `27216`（河内長野市） |

- 地域コード `27216` は総務省「全国地方公共団体コード」（大阪府 河内長野市）。
- 単位（人 / ha / km² 等）は決め打ちせず、APIの戻り値 `@unit` をそのまま表示します（誤表示防止）。
- 最新の統計年次を自動選択して表示します。

### 主なリクエストパラメータ
`appId`, `statsDataId`, `cdArea=27216`, `cdCat01`（項目コード）, `lang=J`, `metaGetFlg=Y`, `cntGetFlg=N`, `callback`（JSONP）。

### エラー処理
- ID未入力：取得前に警告表示。
- APIエラー：`GET_STATS_DATA.RESULT.STATUS`（0以外）を検知し、`ERROR_MSG` を表示。
- データ無し／JSONP読み込み失敗／タイムアウト（20秒）：それぞれ分かりやすいメッセージを表示。
- 面積は best-effort 実装（面積取得に失敗しても人口は表示）。

## 既知の「要確認」点
この実行環境はプロキシの都合で e-stat.go.jp へ到達できず、**作成側でのライブ動作テストは未実施**です。以下は俊さんのブラウザでの実地確認をお願いします。

- **statsDataId の有効性**：社会・人口統計体系は年次更新でIDや項目コードが変わることがあります。人口が表示されない場合は、画面の「詳細設定」で統計表ID・項目コードを調整してください。最新IDは e-Stat のデータセット画面で確認できます。
- **面積の統計表 / 単位**：総面積 `B1101`（自然環境 `0000020202`）を既定にしていますが、表構成・単位はご確認ください（要確認）。
- **JSONPコールバック仕様の細部**（`app/jsonp/` パス・`callback` 名の受け渡し）はAPI仕様3.0版に基づく実装です。万一動かない場合はエンドポイント／パラメータを併せてご確認ください。
