# 自治体データマップ ─ e-Stat 実データ取得サンプル（近畿・複数指標版）

概算・ダミーだった従来版に対し、**e-Stat（政府統計の総合窓口）API から近畿地方の市区町村を選び、複数の指標を実データで取得し、出典・統計年次つきで表示する**プロトタイプです。サーバー不要、単一の `index.html` だけで動きます。既定表示は河内長野市。

> ★ 重要：**アプリ内プレビューでは動きません。** 必ず実ブラウザ（Chrome / Safari 等）で開いてください（JSONPの `<script>` 読み込みがプレビュー環境ではブロックされるため）。動作確認済み：Chrome。

## 使い方（4ステップ）

前提：e-Stat のアプリケーションID（無料）を取得済みであること。

1. **ファイルを開く** … `index.html` を **Chrome / Safari 等の実ブラウザ** で開きます（アプリ内プレビュー不可）。
2. **IDを貼る** … 「e-Stat アプリケーションID」欄にIDを貼り付けて「保存」。
3. **自治体を選ぶ** … 「府県」を選び、「市区町村の一覧を読み込む」を押すと、その府県の市区町村がプルダウンに出ます。目的の市区町村を選択（既定は河内長野市）。
4. **取得する** … 「選択した自治体のデータを取得」を押すと、人口・世帯・年齢構成・面積・人口密度などが、出典「政府統計の総合窓口（e-Stat）」と統計年次つきで表示されます。

IDはお使いのブラウザ内（`localStorage`）にのみ保存され、コードやリポジトリには一切残りません。共有PCでは使用後に「クリア」を押してください。

## 対応範囲

### 選べる自治体（近畿地方 7府県）
三重県(24)・滋賀県(25)・京都府(26)・大阪府(27)・兵庫県(28)・奈良県(29)・和歌山県(30)。
市区町村リストは**ハードコードせず、e-Stat のメタ情報（getMetaInfo の area 区分）から動的に生成**し、選択した府県コード（先頭2桁）で絞り込みます（府県計 `××000` は除外）。

### 表示する指標

| 指標 | 取得元 cat01 / 算出 | 出典表 |
|---|---|---|
| 総人口 | `A1101` | 0000020201 人口・世帯 |
| 世帯数 | `A7101` | 0000020201 |
| 年少人口（0〜14歳）＋比率 | `A1301`（比率は算出） | 0000020201 |
| 生産年齢人口（15〜64歳）＋比率 | `A1302`（比率は算出） | 0000020201 |
| 老年人口（65歳〜）＋高齢化率 | `A1303`（高齢化率は算出） | 0000020201 |
| 総面積（ha、km²換算も併記） | `B1101` | 0000020202 自然環境 |
| 人口密度（人/km²） | 総人口 ÷ 面積km²（算出値） | ─ |

- 各人口区分の比率・高齢化率・人口密度・km²換算は、生データからクライアント側で算出（「算出値」と明記）。
- 単位は決め打ちせず、APIの戻り値 `@unit` をそのまま表示（誤表示防止）。
- 各指標に最新の統計年次を併記。取得できない指標は「データ無し（要確認）」と安全表示し、他指標の表示は止めません。

## 技術メモ

### エンドポイント（JSONP形式・CORS回避）
- getStatsData：`https://api.e-stat.go.jp/rest/3.0/app/jsonp/getStatsData`
- getMetaInfo：`https://api.e-stat.go.jp/rest/3.0/app/jsonp/getMetaInfo`

JSONP（`callback` パラメータ＋`<script>`タグ）を使うため、CORSの制約を受けず**サーバー・プロキシ無しの純クライアントサイド**で動作します（Chromeで実機確認済み）。将来、APIキーをサーバに隠す／レート制御する場合はサーバ経由へ切替も選択肢。

### データ取得の設計
- 各自治体につき、人口・世帯表（`0000020201`）と自然環境表（`0000020202`）を **cat01で絞らず1回ずつ取得**し、必要な項目コードをクライアント側で抽出（1自治体あたり2リクエスト）。
- 取得項目コードは「詳細設定」の入力欄（カンマ区切り）で追加・変更可能。統計表ID・地域コード・面積項目コードも調整可能。

### 主なリクエストパラメータ
`appId`, `statsDataId`, `cdArea`, `lang=J`, `metaGetFlg=Y`, `cntGetFlg=N`, `callback`（JSONP）。

### 使用した項目コード（WebSearchで実在確認済み）
`A1101` 総人口 / `A7101` 世帯数 / `A1301` 年少人口(0〜14) / `A1302` 生産年齢人口(15〜64) / `A1303` 老年人口(65〜) / `B1101` 総面積。

### エラー処理
- ID未入力・地域コード空：取得前に警告。
- APIエラー：`RESULT.STATUS`（0以外）を検知し `ERROR_MSG` を表示。
- データ無し／JSONP読込失敗／タイムアウト（20秒）：分かりやすいメッセージ。
- 面積表の取得に失敗しても人口側は表示（best-effort）。

## 既知の「要確認」点
作成環境は e-stat.go.jp へ到達できず、**私（作成側）でのライブ検証はできません**。以下は俊さんのブラウザでの実地確認をお願いします。

- **statsDataID・項目コードの有効性**：社会・人口統計体系は年次更新でID・コードが変わることがあります。表示されない指標が出たら、画面の「詳細設定」で統計表ID・cat01・面積項目コードを調整してください。
- **世帯数 `A7101`／面積 `B1101` の単位・年次**：表構成により単位表記が異なる場合があるため、画面の統計年次・単位表示をご確認ください。
- **農業産出額など農業系指標**：この2表には含まれません。別統計（生産農業所得統計・農林業センサス等）の別 statsDataId が必要で、**本版では未搭載＝将来拡張**（要確認）。
- **市区町村リストの網羅性**：メタの area 区分から生成しています。政令市の区・市の総計など粒度が混在する場合があります（コード末尾 `000` の府県計のみ除外）。
